# Managed Switch Card for Home Assistant

This repository is archived. The card is part of the integration
[Managed Switch (SNMP)](https://github.com/eizedev/ha-managed-switch) from version 0.6.0: it loads
in Home Assistant on its own and is updated with the integration. Its source is in
[`card/`](https://github.com/eizedev/ha-managed-switch/tree/main/card) there, and the
documentation is at [ha-managed-switch.eize.dev/card](https://ha-managed-switch.eize.dev/card/).

If you installed the card from this repository: update the integration to 0.6.0 or newer, then
remove *Managed Switch Card* in HACS and its entry under *Settings*, *Dashboards*, *Resources*.
Your cards keep working.

Issues and layouts for new switch models go to
[ha-managed-switch](https://github.com/eizedev/ha-managed-switch/issues).
